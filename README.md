# 项目简介

## 核心功能
- 提供基于YOLOv8的火焰烟雾检测系统完整源码
- 包含21527张火焰烟雾数据集，分为smoke和fire两类
- 训练好的模型及完整的训练结果
- 项目运行教程和环境配置指导
- 支持多种检测方式：单张图片、图片文件夹、视频文件和本地摄像头
- 界面实时显示目标位置、目标总数和置信度信息
- 支持自定义置信度和IOU阈值
- 可选择显示标签和原图
- 支持选择不同检测模型
- 支持批量检测并直接查看所有检测结果
- 支持检测结果保存功能

## 适用场景
- 工业安全监控
- 森林火灾预警
- 建筑物火灾检测
- 安防系统
- 环境监测
- 科研实验

## 技术特点
- 基于YOLOv8目标检测算法
- 使用Python 3.9开发环境
- 集成OpenCV-Python进行图像处理
- 采用PyQt5构建用户界面
- 依赖Ultralytics和PyTorch深度学习框架
- 提供完整的UI界面源文件和图标资源
- 包含详细的运行教程和环境配置说明
